# Provenance Before Prose：数字都对，为什么结论还是错？

> 精读日期：2026-11-23  
> 原题：Provenance Before Prose: Claim-Locked Reporting for Statistical Text Generation  
> 作者：Xiao Fan、Jingyuan Li（通讯作者）、Hongbin Guo、Yubo Han、Yi Zhang（通讯作者），均署名西安电子科技大学。

> [ACL Anthology](https://aclanthology.org/2026.emnlp-main.357/) · [15页正式PDF](https://aclanthology.org/2026.emnlp-main.357.pdf) · [公开参考实现](https://github.com/XiuFan719/Claim-Locked-Reporting)

## 一、真正会漂移的是“这句话断言了什么”

先看一个很简单的情形：模型引用了表里正确的 85.9% 和 79.5%，却把 85.9% 写成“更低”。或者它正确抄出改动前后的结果，却把“在这个对照下有帮助”改写成“采用这个方法是必要的”。数字检查和来源检查都可能漏掉这些错误，因为错的是数字之间的关系，或者证据所允许的断言强度。作者在[公开仓库](https://github.com/XiuFan719/Claim-Locked-Reporting)自述，其论文的一份 AI 审稿恰好出现了这两种错误；这是附带案例，不是独立的系统性审稿评估。

论文提出，把报告首先看成**一组有出处、有条件、有方向和措辞上限的统计结论**，而不是段落。先确定可说什么，再让模型决定怎么衔接。确定性模板本来就会稳定地打印给它的数字，作者追问的是：谁决定数字进入模板？如果选择仍由采样的模型完成，每次都能打印得很精确，报告却可能每次在说不同的事。

从[西电团队页面](https://web.xidian.edu.cn/zhangyi/team.html)可核实 Xiao Fan、Jingyuan Li、Yi Zhang 等此前共同开展动态功能连接研究；通讯作者 Yi Zhang 的[学校主页](https://web.xidian.edu.cn/zhangyi/)列其为教授及脑影像中心负责人。本文的主要贡献是报告可靠性设计，影像数据用于检验方法，不把结果读成临床或生物机制发现。

## 二、图1：同一份证据，三种控制权限

论文演示的证据记录里有两个模型：第一个分析得到10,041个通过统计筛选的连接，加入作为分组依据的连续变量后只剩8个。

- **文本层**：给模型证据、提醒它认真写，或要求 JSON、引用出处。模型仍能挑结果、改数字、改方向和口气。在图1示意里，模型甚至把10,041写成约15,000，还顺势加强解释。
- **槽位层**：允许模型选内容，再用代码写规范模板。它可以无错地打印10,041，却只选择这个数字而不写调整后的8，读者仍可能误以为这是一个独立效应。
- **结论层**：先锁死这是一项调整前后对照，绑定10,041和8、调整后明显减少和谨慎表述。最后的文采不能决定该不该把对照的一半省掉。

模板锁的是句子的“外壳”，账本锁的是一句话的统计含义。关键对照是混合模板与完整方法，两者都确定性渲染，但输入渲染器的内容由谁决定不同。附录表A1也提醒，后验审稿需先任由模型写出断言，再尝试补救；它不是同一个控制位置。

## 三、怎样把一项结论锁住？

### 3.1 分析先形成结构化记录

功能磁共振成像（fMRI）的功能连接分析先基于脑区之间的连接矩阵，对各边拟合广义线性模型（GLM）。如果有 N 个脑区，无向不同区域对有 N(N−1)/2 个。很多边一起检验容易产生假阳性，论文用 Benjamini–Hochberg 控制错误发现率（FDR）。输出记录保存筛过的连接数、区域或枢纽摘要、代表连接及调整前后结果。脑区和受试者原始数据不交给写作者重算。

随机对照试验（RCT）另有较简单的记录：干预、对照、观察结果、上游已裁定的方向标签，以及支撑它的原文片段。两领域共用结论结构和控制接口，但不会共用领域判断规则。

### 3.2 结论构建器、风险审计、政策约束分别负责什么

1. **构建账本**：每个条目包含类型、结论身份、规范文本、解析到分析阶段的证据指针、拟报告数值和方向、文献支持等级、措辞强度。指针没有落点的材料不能变成可展示断言。附录A.1的示例把10,041、8和99.9%的降幅放在同一条。
2. **只读审计**：检查数字能否追溯，方向有没有翻转，实体/来源是否支持，结论适用范围是否越界，措辞是否太强。它标风险并说明动作，不自己改原结论。附录表A3说明，影像任务要留意协变量、筛选偏差和探索性结果，试验任务则重点是干预、对照、结局与适用人群。
3. **政策单向降级**：只能保持、减弱或禁用某条结论，不能把既有证据许可升级。示例里，身体质量指数（BMI）本来用来生成组别，再用连续 BMI 调整，必须将两项结果一起叙述，并禁止写成独立组别效应或独有机制。
4. **拆开两个生成通道**：代码由账本确定性地打印数值、表格、实体和方向标签；模型只写短连接段落，受措辞与结构约束。论文协议在输出外壳不合法或缺必需小节时拒绝生成部分报告。连接段依然需要核对，不能仅凭“规定只写连接文字”就宣称任意隐含语义都能被程序证明。

这套分工可以追查错误出现在哪：上游统计、身份/指针、政策过强，还是连接段偷偷改变关系。它不会让错误数字因为进入账本就变正确。

## 四、怎么评价：稳定、得体、正确是三个问题

- **跨种子复现率（Repro.）**：用报告可见数值集合的 Jaccard 重叠衡量。例：两次报告分别带有{10,041, 8}和{10,041, 550}，交集一个、并集三个，重叠为1/3。论文会过滤常见章节号等，使用绝对误差10⁻³或相对误差5%作匹配，所以98.5%不是逐字符一致，也不是结论语义准确率。
- **措辞治理（Strong/Hedge）**：Strong 检测一句有强断言用语却没有相应限定；Hedge 只在有风险标签的结论上看是否加了谨慎表达。词典可能误判否定，也可能漏掉委婉的过度断言。它不是鼓励每句话都加“可能”。
- **逐份正确性（Num、方向审计）**：Num 检测证据、白名单衍生量及常用常数以外的可见数字，并不验证所有计算和关系。方向在人审中另判保留、倒转或不明确。影像的词典方向检查抵不住否定和比较句式，只作为补充。

图2把复现错误率的标准分放横轴，把 Strong 与负向 Hedge 的标准分平均后放纵轴。影像任务的锁定法两轴都靠低端；试验任务主要优势在横轴，并非每项治理指标都最佳。图中的位置用于展示权衡，不是把三种可靠性合成一个能排名所有方法的总分。

## 五、第一组结果：影像报告中，模板为什么仍会漂移？

每方法有两个队列（机构队列428人、公开 HCP 队列712人）、两个写作者、五个种子，即20个生成格。受试者数不是写作比较的独立重复数。写作者为 Kimi K2.6（温度1.0）和 DeepSeek V4 Pro（0.7），在同一提供商/记录/种子下所有方法给相同证据；两提供商温度不同，不能把跨提供商差异都归因于方法。五种其余基线分别是自由写、忠实性提示、结构输出、同记录检索引用和后验复核。

表1中，传统五个文本基线复现为15.2%–32.3%；混合模板是61.1%，锁定法是98.5%，改善37.4个百分点，95%配对 bootstrap 区间[15.1,59.7]。Strong 从2.25降到0.75句，相差−1.50句，区间[−2.05,−1.00]；风险限定 Hedge 从0.25到0.39。两者 Num 都为0。只看这一列会错过混合模板内容每次换的问题。仅公开 HCP 队列也得到98.0%对62.0%，自由写46.0%。配对重抽20,000次保留了匹配结构，仍只有两个独立队列，不能把20格读成验证了20个不同队列。

表3是标题中“先问出处”的最好例子：机构队列10,041→8，公开 HCP 队列550→0。改动后的比较改写了结论的适用范围，而非原数字抄错。这是组别和其派生变量的循环风险压力测试，不是证实疾病机制；更不能从加入连续变量后的变化直接读出因果原因。

### 什么组件起什么作用，额外成本是多少？

附录表A2从仅构建账本、加确定性渲染、到开启完整审计和政策。影像复现率85.0%→98.0%→98.5%，Strong 1.60→1.40→0.75。试验数字复现90.3%→100%→100%，Strong 为0→0.015→0.010，原本就很低。由此更适合说渲染稳定了数字，审计和控制主要改善影像的措辞。后两模块一起启用，实验没有拆出它们各自的独立贡献。

表2只统计 DeepSeek 写影像报告的一组设置。完整方法输入12,482 token、输出4,209、中位延迟77.3秒；混合模板为21,213、7,069、123.9秒；自由写20,603、5,432、111.9秒；后验复核44,434、16,687、295.2秒。完整方法一次写作调用，后验复核两次，代码处理相对短。该表是写作阶段账单，不包括上游分析、文献标签构建或跨领域配置成本，也不能外推到价格更低或缓存不同的服务。

## 六、第二组结果：到了试验报告，告警更多反而不一定更危险

Evidence Inference 2.0 保留200条按文章去重、标注一致、证据至少两个数字的记录，其中方向为显著增加112、显著减少88，无显著差异的类别不进入实验。两个写作者×两个种子，每方法800格。

表4的短输出更容易稳定，结构输出基线已达到90.0%，高于79.5%的混合模板，说明控制层级并不自动形成单调排行榜。锁定法100%，相对混合+20.5点，95%区间[17.8,23.1]。但 Num 原始指标混合0.11更低，锁定0.23；Hedge 为0.19对0.10。不能因为一个方法主张更可靠，就把这些列藏掉。

## 七、人审及外部评分各自看见什么？

表5的方向盲审在30条试验记录上生成840份报告，每法120份。一位评审判全部，第二位独立核分层50份，原始一致49/50，Cohen κ=0.970。锁定法116份方向正确、0倒转、4不明确；混合102正确、17倒转、1不明确。倒转率为倒转/(正确+倒转)，所以0%不等于120份全部正确。它测试的是保护给定标签，不是从论文自动推断方向的能力。

附录表A4的影像片段由四名不知方法的评审独立判断。自由写、混合、锁定的未限定强断言均值分别2.55、1.85、0.60，不支持内容均值则为1.65、2.33、0.53。这是对自动指标排序的一次局部确认，人工口径比自动实体词典更宽。它不等同于覆盖全部报告的专业审稿，也没有证明读者更喜欢文风。

表6用同一30条试验记录比较事实支持评分 FActScore 和跨生成一致性 SelfCheckGPT。锁定法前者0.552最低，后者0.974最高；基线里后验复核 FActScore 0.856。论文举例：一句话用了原文数字却把降低说成升高，FActScore 给1.00；另一句用2.77到5.76正确表达增加，反而给0.00。这里的 FActScore 应按论文实现及案例解读，不宜泛称该指标只做字符串匹配。两种指标既不直接测试统计关系，也不能替代单独的方向人审。

## 八、读完要记住什么，迁移时先做什么？

1. **证据来源、数字、比较方向和表述上限是一组约束。** 只固定其中一项，仍可能写出另一项错误。
2. **先问谁选择报告内容。** 确定性渲染有用，但如果模型仍能挑最能讲故事的数字，跨种子复现与结论选择可能漂移。
3. **报告稳定性不是结果真实性。** 上游预处理、统计模型、条件、证据提取和文献支持标记若有错，账本可以稳定地传下去。两领域模板也需要重新设计，尤其试验没有验证无差异和不确定的标签，不能强塞正负方向。
4. **公开工件可验证方法骨架，尚不能完整复跑论文。** 作者的真实公开仓库有合成示例、最小账本、审计、渲染和测试，并只披露两份代表性提示。论文附录提及更完整提示与可披露材料，但当前仓库 README 明确未提供全提示、数据适配和实验编排；私有影像队列也不可重发。应按实际公开范围判断可复现性。公开实现禁用连接文字中的数字属于具体防护，并不能阻止用无数字措辞反转含义。
5. **仍要让人核对条件与所许可的结论。** 把小样本人审和词典告警当诊断证据，避免把两种写作任务的可靠性提升推成普适规则。

借到软件工程的实验写作，最容易落地的版本是给每句核心结论保存一行账本：同一实验版本、比较两臂、统计单位、分母和聚合方式、点估计及区间、异常如何处理、可用的最强措辞。同一张表上出现不同分母或交叉验证条件时，先把有效范围与数字绑定。留出评估未做就写“未验证”，区间跨过质量门槛就写“未确立非劣”。这样做只能提升报告对既有证据的忠实度，仍需独立检查实验设计、选择偏差和效应解释。
