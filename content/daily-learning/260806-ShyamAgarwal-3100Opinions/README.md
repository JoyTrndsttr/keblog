#### 一句话结论

论文把从业者关于 AI 代码审查的分散观点组织成了包含 **26个构念和67条关系**的因果理论，但这些关系目前是**待检验的因果假设**，不是已经估计出的因果效应。

#### 研究问题与动机

现有研究经常统计：

- AI PR 的合并速度是否更快；
- 人类审查是否减少；
- 评论数量和审查深度是否变化；
- 自动审查是否提高质量。

但同一个现象会随着操作化定义改变而得到相反结论。例如，“提交 AI PR 的调用者”是否算独立审查者，会直接影响“无人审查比例”。

因此，作者不急于估计单个效应，而是先追问：

> AI 生成代码通过哪些认知、行为和组织机制改变代码审查，最终又影响哪些结果？

#### 方法流程

1. 收集 38,709 份公开讨论材料，包括 7,630 篇网页文章和31,079个 Reddit 讨论串。
2. 对候选材料进行相关性筛选；23,631份候选中保留13,469份，抽样一致性为 Cohen’s κ=0.75。
3. 聚焦2025—2026年的约9,100份材料，再分层抽取3,100份。
4. 使用三个具有不同立场的 Gemini 2.5 Flash 编码代理：
   - 中立编码者；
   - 批判性编码者；
   - 积极评价编码者。
5. 作者进行轴心编码和选择性编码，将底层观点归纳为构念、关系和理论命题。
6. 最终代码簿包含4,838个编码，依据来自2,669份文档中的109,951处引文。

#### 数据、基线与评价方式

这不是模型性能比较论文，因此没有传统的生成基线和准确率指标。

其质量控制主要包括：

- 多来源语料；
- 分层抽样；
- 不同立场的多代理编码；
- 人工归并和理论构建；
- 相关性筛选的一致性检验。

真正应关注的不是“编码模型比某基线高多少”，而是构念是否完整、关系是否有足够语料支持，以及理论能否被后续实验证伪。

#### 主要结果

作者总结出：

- **26个构念**；
- **67条关系**，其中64条有明确方向，3条存在争议；
- AI 代码数量与速度、表面可信度、代码不透明性、输出不稳定性以及数据/IP风险，是重要驱动因素。

部分代表性命题：

- 审查负荷增加，会降低审查深度；
- 负荷还可能通过降低审查动机，间接降低审查深度；
- AI 代码“表面上很合理”可能减少深入检查，从而降低审查有效性；
- 对 AI 的怀疑可能提高审查深度，但降低效率；
- 缺少生成意图和推理过程会降低审查效率、有效性和动机；
- 完全自动化可能提高吞吐量并缩短延迟；
- 自动化对质量与安全的影响仍存在争议。

论文引用的 GitHub 观察还发现：

- 40.1%的 Agent PR 只由调用者检查，而人类 PR 对应比例为21.5%；
- 2025年中期，超过一半的 Agent PR 没有独立人类审查；到2026年初，该比例下降至约14%。

这些是观察性描述，不能直接解释为 Agent 导致了审查行为变化。

#### 局限与威胁

- 语料反映的是公开表达的观点，不一定等同于实际行为。
- Reddit 和技术文章可能偏向积极采用者或意见强烈的人。
- 部分网页内容本身可能由 LLM 生成。
- LLM 编码可能遗漏语境或引入立场偏差。
- 构念与关系最终仍依赖作者的理论判断。
- 理论中存在反馈回路，不能直接整体转换成用于识别的 DAG。
- 当前没有干预、自然实验或有效的混杂控制，因此不能估计因果效应大小。

#### 与 Causality for Code Review 的具体联系

这篇论文最适合当作**因果问题发现器和候选变量库**。

不要试图一次验证完整理论。更可行的路线是选择一条边，例如：

> AI 代码的表面可信度 → 审查深度 → 缺陷发现率

然后明确：

- Treatment：AI 标识、表面流畅度或生成来源；
- Mediator：审查深度、阅读时间、查看文件数量；
- Outcome：真实缺陷发现率；
- Confounders：变更规模、代码复杂度、审查者经验、模块熟悉度、任务紧急程度；
- Estimand：ATE、ATT，或者按审查经验划分的 CATE。

其中“表面可信度”不能仅靠真实历史数据可靠测量，比较适合受控实验：保持代码完全相同，只改变其是否被标记为 AI 生成，观察审查行为和缺陷发现是否变化。

#### 可直接借鉴的实验或写作点

1. **从理论图中选择一条可识别的路径。**
   明确说明完整理论包含反馈环，因此本文只研究某个局部无环子图。

2. **区分独立审查者与 AI 调用者。**
   把 reviewer definition 作为敏感性分析维度，避免操作化定义左右结论。

3. **同时报告机制变量和最终结果。**
   不只看合并时间或评论数量，还测量审查深度、理解程度、缺陷发现和修复质量。
