## 一句话价值

分析覆盖率机器人采用前后的 PR 活动变化，并强调采用时点的观察性识别假设。

#### 必读一：研究设计到底是什么

作者以代码审查机器人首次投入使用为干预点，比较同一项目干预前后各约一年内的月度 PR 活动。

输入是项目月度数据，核心操作是拟合分段回归，输出包括：

- 采用机器人当月是否出现水平跳变；
- 采用机器人后，原有变化趋势是否发生改变；
- 项目及编程语言差异能解释多少额外方差。

论文称其为 Regression Discontinuity Design，但更准确地说，它接近**以采用时间为断点的受控中断时间序列**。经典 RDD 通常依赖阈值两侧样本近似随机分配；这里所有项目都在某个时间点主动采用机器人，因此识别主要依赖：

> 如果没有机器人，结果会沿采用前趋势继续发展，并且采用时没有其他同时发生的干预。

这个假设没有办法只靠回归拟合本身证明。

**读完这一节，你只需要记住：该设计比简单的 before/after 比较强，但尚未达到随机实验式的因果识别强度。**

#### 必读二：数据、Treatment 与 Outcome

- **Dataset：** 1,194 个 GitHub 开源项目，观察机器人采用前后共 24 个月；原始候选来自 GHTorrent。
- **Treatment：** 项目开始使用 Codecov、Coveralls 等覆盖率审查机器人。
- **Outcomes：**
  - 每月合并/未合并 PR 数；
  - PR 评论数中位数；
  - 合并或关闭耗时中位数；
  - 每个 PR 的 commit 数中位数。
- **模型：** 8 个混合效应回归模型，即 2 类 PR 状态 × 4 类结果。
- **校正：** 使用 Benjamini–Hochberg 控制多重检验。
- **随机效应：** 项目和编程语言。
- **控制变量：** 项目年龄、PR 作者数、累计 commit 数、当月打开的 PR 数等。

值得特别警惕：其中一些“控制变量”可能也会受到机器人采用影响。若控制了 treatment 之后才形成的变量，就可能产生 **post-treatment bias**。是否应调整，必须先画时间顺序明确的 DAG，不能仅凭“该变量与结果相关”决定。

**读完这一节，你只需要记住：变量不少不等于混杂控制充分；每个控制变量都需要因果角色论证。**

#### RQ 与证据链

**RQ1：采用机器人后，PR 活动是否变化？**

→ 对 1,194 个项目建立干预前后分段混合效应模型
→ 比较即时跳变与采用后的趋势变化
→ 主要发现：

- 合并 PR 数在采用后增长得更快；模型 \(R_m^2=.68\)，\(R_c^2=.75\)。
- 未合并 PR 数呈下降趋势；模型 \(R_m^2=.67\)，\(R_c^2=.74\)。
- 已合并 PR 的人类评论减少；模型 \(R_m^2=.50\)，\(R_c^2=.56\)。
- 未合并 PR 的评论没有观察到稳定的长期机器人效应。
- 合并耗时存在即时跳变，但没有稳定长期趋势效应。
- 未合并 PR 的关闭耗时从采用前上升转为采用后下降。
- commit 数主要表现为采用时的即时变化，没有稳定长期效应。

这些证据可以支持“采用时点前后存在系统性变化”，但把全部变化归因于机器人需要额外假设。

**RQ2：为什么会出现这些变化？**

→ 访谈 12 名使用过审查机器人的开发者
→ 参与者认为覆盖率反馈提高了状态透明度与维护者的合并信心，并使贡献者在没有人类讨论的情况下自行修改代码。

这部分支持的是**可行机制解释**，不是对中介效应的正式检验。访谈对象在看到定量结果后解释原因，也存在 confirmation bias 风险。

#### 局限与可质疑点

**作者承认的局限**

- 机器人采用不是随机事件；
- 项目采用机器人时可能同步改变其他开发流程；
- 数据集中主要是较早期的覆盖率机器人；
- 访谈样本只有 12 人，且部分来自个人联系和滚雪球招募。

**进一步值得质疑**

1. **同期干预：** 团队可能同时引入 CI、测试规范或维护制度，断点效应未必来自机器人。
2. **选择偏差：** 能保持采用前后持续活跃并通过筛选的 1,194 个项目，可能本身就是治理较成熟的项目。
3. **处理后变量：** 当月 PR 数、作者规模或累计活动变量的因果角色需要 DAG 支撑。
4. **聚合偏差：** 月度中位数会掩盖 PR 难度、贡献者经验及项目规模对应的异质效应。
5. **Treatment 太粗：** “已采用”没有体现机器人实际评论强度、配置严格度及反馈是否被开发者看到。
6. **外部效度：** 覆盖率 bot 的效应不能直接外推到 LLM Code Reviewer。
